# CarMori

CarMori is a bilingual vehicle-care web application for car owners in Japan.

## MVP features

- Japanese and English interface
- Vehicle profile and maintenance schedule
- Existing-parking and partner-storage customer journeys
- Service and storage quote requests
- Quote approval and booking status
- Service history
- Responsive mobile and desktop layout
- Browser-local demo data for prototype testing

## Run locally

Open `index.html` in a browser, or start a local static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Current scope

This repository contains an interactive front-end MVP. Authentication, shared database storage, payments, partner integrations, and production notifications will be added after the pilot workflow is confirmed.
