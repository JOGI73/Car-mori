# Car-mori# CarMori

CarMori is a vehicle maintenance, booking, and partner-storage platform for car owners in Japan.

## Planned Features

- Vehicle registration
- Maintenance reminders
- Service booking
- Quote approval
- Service history
- Partner vehicle storage
- Japanese and English support

https://carmori.pages.dev/

## Status

CarMori is currently preparing for pilot launch in Japan.
